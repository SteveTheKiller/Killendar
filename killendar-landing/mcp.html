Install KillerMCP

KillerMCP includes all 81 KillerTools utilities plus tools from supported Killer apps in one local connection. You will not need a separate Killendar installer, a source checkout, Node, or a list of commands.

Windows installer v0.1.0 coming soon
  1. Download and run KillerMCP Setup. The download button will appear here as soon as the signed public installer is released.
  2. Let setup connect your agent. It installs the shared runtime and registers KillerMCP with Codex, Claude Code, Claude Desktop, Cursor, GitHub Copilot, Gemini CLI, and Windsurf when found.
  3. Open a new agent chat and ask. KillerMCP detects Killendar on your computer and makes its calendar tool available through the same connection.

Optional hosted KillerTools connection

Do not want to install anything yet? The hosted endpoint provides 64 web based KillerTools utilities without an installation. It does not provide the remaining 17 KillerTools utilities, Killer app tools, or access to your local Killendar calendar.

What it can do

KillerMCP gives your agent read-only access to the active calendar in Killendar, including recurring events. It can start from a date you choose and read a range of up to 31 days.

Read your agendaSee events for today, a week, or a date range without opening the app and searching manually.
Understand recurrenceRecurring appointments are expanded into the dates that fall inside the requested range.
Keep changes in your handsThe Killendar tool is read-only. It cannot create, edit, move, or delete appointments.
Keep calendar data localThe command runs on your computer and reads the same local Killendar data used by the app.

Data safety and permissions

The agenda lookup runs locally through the installed Killendar app. It is read-only and returns only the bounded events requested by the MCP client and its agent. The hosted Cloudflare Worker never receives this calendar lookup.

Your MCP client and model provider can still receive event titles, times, notes, and other returned calendar fields. Apply the provider data handling rules before requesting confidential or client calendar data.

How it works

KillerMCP is an open-source local runtime. It includes all 81 KillerTools utilities, detects installed Killer apps, and exposes only the adapters supported by those versions. For this page, it calls the Killendar command line agenda reader and validates the bounded JSON response.

The optional public endpoint is a separate open-source MCP server running as a Cloudflare Worker. Requests sent to that URL are processed on Cloudflare, and lookup tools may contact their named public sources. It cannot reach your local calendar.

Current limits

A request can cover up to 31 days and return up to 100 events. Password-protected Killendars cannot currently be unlocked through MCP. The public installer is still being prepared and has not been released.

One connection for the family

Install KillerMCP once. It detects supported Killer apps on your computer and adds their tools to one agent connection. As more app integrations are released, the same KillerMCP runtime can provide them without a separate installer for every app.
