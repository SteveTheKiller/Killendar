Install KillerMCP

KillerMCP includes all 81 KillerTools utilities plus tools from supported Killer apps in one local connection. You will not need a separate Killendar installer, a source checkout, Node, or a list of commands.

  1. Download and run KillerMCP Setup. Use the signed installer above.
  2. Let setup connect your agent. It installs the shared runtime and registers KillerMCP with Codex, Claude Code, Claude Desktop, Cursor, GitHub Copilot, Gemini CLI, and Windsurf when found.
  3. Open a new agent chat and ask. KillerMCP detects Killendar on your computer and makes its calendar tools available through the same connection.

Try asking

killer is the shortest form. Your agent can infer Killendar when the request is clearly about your calendar. Use killendar when you want to make the app explicit.

What it can do

KillerMCP reads the active calendar, including recurring events, and creates single appointments through the running app.

Read your agendaSee up to 31 days of events without opening the calendar window.
Understand recurrenceRecurring appointments are expanded into the dates inside the requested range.
Create appointmentsAdd a timed or all-day appointment while Killendar is open and unlocked.
Keep edits in the appEditing, deleting, and setting up recurring appointments still happen in Killendar.

Data safety and permissions

The agenda lookup reads the local file without changing it. Creation goes through the open Killendar app, so its calendar updates immediately. Your MCP client and its model provider can receive the appointment details sent to and returned from these tools.

How it works

KillerMCP connects your AI assistant to supported Killer apps installed on your computer. It finds Killendar and offers an agenda tool for bounded, read-only queries. The create tool sends a validated appointment to the running, unlocked app, which saves it and refreshes the calendar. The commands run on your computer, not on this webpage.

Current limits

  • An agenda request can cover up to 31 days and return up to 100 events.
  • Agenda lookup cannot unlock password-protected Killendars.
  • Creating an appointment requires Killendar to be open and unlocked.
  • Editing, deleting, and creating recurring appointments still require the app interface.

One connection for the family

Install KillerMCP once. It detects supported Killer apps on your computer and adds their tools to one agent connection. As more app integrations are released, the same KillerMCP runtime can provide them without a separate installer for every app.
